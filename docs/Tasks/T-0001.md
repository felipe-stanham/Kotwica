# T-0001: tst manages its own Managed Record (kotwica-tst)

**Status:** [DONE] | **Branch:** `task-T-0001-tst-managed-record` | **Created:** 2026-10-15 | **Parent:** [P-0001](../Projects/P-0001.md)

## Why

P-0001 made tst watch-only and did not deploy Kotwica there. The first run on the Pi under the real Latarnia contract would then be prd, which writes `home`, the record Caddy's certificate depends on. With a record per environment (`kotwica-dev`, `kotwica-tst`, `home`), Latarnia tst on the Pi exercises the full write path before `home` is touched.

Operator decision: 2026-10-15 (supersedes the spec rows "tst is watch-only" and "Kotwica not deployed to tst").
